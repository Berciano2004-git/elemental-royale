# Convenciones de trabajo

## Guardado en GitHub

- Remoto: `origin` → https://github.com/Berciano2004-git/elemental-royale (público, rama `main`).
- **Cada cambio terminado se commitea y se sube** en el mismo momento, sin esperar a que el usuario lo pida.
- Mensajes de commit en español, breves y centrados en el motivo del cambio.
- Verificar antes de subir que `npm run build` pasa y que no se cuelan secretos.
- Nunca subir `node_modules/`, `dist/`, `screenshots/`, `tmp-rig/`, `tmp-inspect/` ni ficheros `.env`.

## Estilo del proyecto

- Interfaz y textos en español; estética low-poly generada por código.
- El servidor es autoritativo: el cliente no decide posición, daño ni economía.
